### Execution (Start)
`node Block.js example.block`

### Syntax & Examples

* **Print to Console (log)**
  ```json
  ["log", "Hello, World!"]
  ```

* **Variable Assignment (set)**
  ```json
  ["set", "score", 100]
  ```

* **Increment (+)**
  ```json
  ["+", "score"]
  ```

* **Decrement (-)**
  ```json
  ["-", "score"]
  ```

* **Loop Statement (while)**
  ```json
  ["while", "i", 0, ["-", "i"]]
  ```
